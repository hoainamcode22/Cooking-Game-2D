# 📥 BỎ FILE PNG VÀO THƯ MỤC NÀY

Vẽ xong bỏ file `.png` thẳng vào đây. **Không tạo thư mục con, không kèm file `.meta`,
không kèm file phụ** (`_v2`, `@2x`, `_final`, file PSD…). Chỉ PNG.

Giao được lô nào giao lô đó — không cần đủ 20 mới gửi.

---

## Tự soát 8 điểm trước khi bỏ file vào (2 phút)

Mở file ở cỡ thật rồi **thu nhỏ xuống bằng móng tay** để soát:

1. ☐ Nền **trong suốt 100%** (hoặc magenta #FF00FF đồng nhất) — không sót viền màu nền quanh mép.
2. ☐ **Không** có bóng đổ rời khỏi bát/đĩa. (Bóng tiếp xúc sát đáy, trong silhouette thì được.)
3. ☐ **Không** chữ, không số, không logo, không watermark.
4. ☐ Món nằm **giữa khung**, không bị cắt mép, chừa lề trống ~8% mỗi bên.
5. ☐ Outline nâu đậm rõ, **nét ngoài dày hơn nét trong**.
6. ☐ Bảng màu **ấm**, không neon, không lấy tím/xanh lam lạnh làm màu chủ đạo.
7. ☐ Mở thư mục `../THAM_CHIEU_ICON_CU/`, đặt file mới cạnh 3 icon cũ bất kỳ —
   **có nhìn như cùng một bộ không?**
8. ☐ **Tên file đúng y hệt** cột "Ten file PNG can ve" trong `../05_BANG_GHEP_FILE_VAO_MON.csv`,
   đủ dấu tiếng Việt, đúng hoa/thường. Khung **512 × 512** vuông.

## Hai lỗi hay gặp nhất ở các đợt trước

**1. Nền trông như đã xoá nhưng thực ra chưa.**
Nhiều công cụ để lại một viền mờ màu nền quanh mép món. Trên nền trắng của phần mềm vẽ thì
không thấy gì, nhưng game đặt icon lên nền gỗ nâu là **lộ ngay thành vệt sáng quanh viền**.
→ Cách tự kiểm: đổi nền phần mềm sang **màu tối** (nâu đậm hoặc đen) rồi nhìn lại mép món.

**2. Vẽ đẹp ở 512 nhưng "chết" ở 38px.**
Icon trong game chỉ hiện ở 38–52 px (xem `../04_KY_THUAT_GHEP_VAO_GAME.md` mục 2).
→ Cách tự kiểm: thu ảnh xuống 40px, nhìn cách màn hình một sải tay. Còn nhận ra là món gì không?
  Còn phân biệt được với 3 món khác cùng lô không? Nếu không thì tăng tương phản,
  giảm chi tiết vụn, cho nguyên liệu chính chiếm mảng lớn hơn.
